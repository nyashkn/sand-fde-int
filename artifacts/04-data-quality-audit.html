Correction to a previous claim

An earlier analysis in this engagement reported staff_trained_on_protocol_pct → NMR at r = −0.844 and used it to argue that facility capability, not geography, explains neonatal mortality. That reading was wrong. The correlation is entirely between-tier and vanishes inside every tier:

POOLED (all 117) r = -0.844 Health Center n=45 r = +0.042 District n=45 r = +0.111 Provincial n=25 r = +0.144

This is Simpson's paradox. Both the capability metric and the death count are drawn from the same tier-level latent, so the pooled figure measures tier, not training. Presenting "train staff → fewer deaths" to a Minister on this evidence would be an ecological fallacy shipped as policy advice — the same error this engagement had already rejected when considering raster covariates.

§1How the data was generated

The three sweeps converge on a four-layer generation model. It matters because each layer supports a different class of claim, and only one layer supports any claim at all.

Layer 1 · real
Administrative structure. District → province mapping is correct 30/30 against Rwanda's actual administrative geography. Facility ids are contiguous 001–117, assigned in unbroken per-district blocks. All five files share an identical facility_id set.
district · province · facility_id
Layer 2 · tier bands
Tier-stratified uniform draws. Volume and capability metrics are uniform-random within a per-tier band. Globally the distribution looks structured (uniform-sd-ratio 0.56–0.83) because it is a mixture of four non-overlapping bands; within a tier the ratio returns to 0.89–1.05. ICC for total_deliveries is 0.887 — 88.7% of variance sits between facilities.
total_deliveries · live_births · all 6 governance percentages
Layer 3 · pure noise
Independent uniform draws with no anchor. Clinically interlinked conditions show zero measured association with each other. avg_gestational_age is a textbook fingerprint: uniform-sd-ratio 1.004, quantised to 0.1, edge bins at ~40% of interior weight — the exact signature of uniform(36.45, 38.55) rounded to 1dp, with no facility identity signal at all.
avg_gestational_age · apgar_less_7 · birth_weight_less_2500g · preterm_* · stillbirths · gps_lat/lon · staff_per_delivery_2024
Layer 4 · honest
Exact arithmetic identities. These hold with zero exceptions and are the one part of the file that behaves like real bookkeeping. live_births = total_deliveries − stillbirths in 1404/1404 rows; the five cause-of-death columns sum to total neonatal deaths in 1404/1404 rows.
live_births · death_* (as a multinomial split)

§4What is clean

Absence of defect is a result. These were checked and found sound — which is what makes the findings above trustworthy rather than a fishing expedition.

Structural integrity

  • All 5 CSVs share an identical 117-facility id set. Zero orphans across 20 pairwise directions.
  • Facility ids contiguous 001–117, assigned in unbroken per-district blocks.
  • 117/117 unique facility names despite a templated naming pattern.
  • Zero empty or missing cells in any column of any file.
  • Zero malformed dates, zero malformed percentages across 819 percentage cells.
  • District → province mapping correct 30/30 against real Rwanda structure.

Arithmetic and bounds

  • live_births = total_deliveries − stillbirths, exact, 1404/1404.
  • Cause-of-death columns sum to total neonatal deaths, 1404/1404.
  • Preterm total ≤ deliveries; Apgar<7 ≤ live births; LBW ≤ live births; deaths ≤ live births — all 1404/1404.
  • incubators_functional ≤ incubators_total, 0 violations.
  • neonatal_trained_nurses ≤ total_nurses, 0 violations.
  • NICU availability vs bed count consistent in both directions, 117/117.
  • No integer column across 46 shows multiples-of-5/10 rounding bias.

§5What this changes in the build

The bulletin's required metrics

The brief names four bulletin components. Two survive intact, one needs reframing, one cannot be built honestly from this data.

Required metricStatusConsequence
Top 10 facilities by volumeintactRanks tier bands, not performance. Label it as volume, never as quality.
Maternal health indicatorsintactCounts and rates are internally consistent. Clinical relationships between them are not — report each on its own, never jointly.
Facility performance scoresreframeCannot be presented as explaining outcomes. Present as a capability inventory: what a facility has, not what it achieves.
Trend vs previous quartersblockedNo genuine temporal signal exists, and Q1/Q4 are incomplete on top of that. Any month-over-month delta is noise. Either state that plainly or omit the panel.
Why this is the deliverable, not a caveat

The Director's stated problem is "I cannot trust any number I am shown." A bulletin that silently renders a quarter-over-quarter arrow on noise, or a performance score that implies causation it cannot support, confirms exactly that complaint on a quarterly schedule.

Every finding above was produced by a one-line check. Shipped as validation that runs on ingest, they turn an unfalsifiable complaint into a standing measurement — and they generalise past this sample, which is the part that outlives the engagement.

§6Mapping to the triage queue

The rewrite this forces on DUP-01

"Keep the latest submission" is undefendable — nothing in the file establishes row order as submission order, and neither row is more correct by any measurable property. The rule becomes:

DUP-01 — where a (org_unit, period) collision spans a whole batch, the batch is not auto-resolved. Both are retained, the conflict is queued at batch scope, and every derived figure is marked provisional until a resolution exists. Provisional figures state so on the face of the presentation.

This is what lets the bulletin ship before triage is complete, with the affected number visibly labelled rather than silently wrong.

Method — three independent read-only sweeps run in parallel, each blind to the others' findings, against assignment/data/*.csv. Python 3 stdlib only. Every finding required a reproducible one-line check as a condition of being reported; claims without a runnable check were rejected.
Slices — governance + operations column sweep · facilities + healthcare_workers + cross-file referential integrity · distributional fingerprinting and clinical reconciliation.
Limits — the generation model in §1 is inferred from distributional evidence, not from any generator source. Correlations describe this sample only and support no epidemiological claim about Rwanda. The Benford test was run and is reported as inconclusive: the count columns span 1.1 orders of magnitude, too narrow for the law to hold even on genuine data.
